# 系统架构与接口

```text
双OV5640 -> PL采集/双目校正 -> 四路径SGM -> 视差与测距
                  |
                  +-> 中央480x480裁剪 -> 320x320 -> LDS-Net
                                                     |
                        PS: 检测解码/语义后处理/测距融合/UI
                                                     |
                                  PL显示控制与HDMI输出
```

## 硬件

目标器件为XC7Z020。网络与SGM目标时钟100MHz，输入相机画面640×480，SGM使用四路径、64视差。RTL、寄存器映射和固定参数以`src/sgm_yolo/hardware/`及`models/lds_net/contract.json`为准。

## 模型

最终模型为LDS-Net EMA8混合W4A6。普通卷积、ReLU、Add与最近邻上采样构成共享骨干、P4/P5检测头和三类道路分割头。主体使用4位权重和6位激活；首层与末端卷积保留8位权重。舍入采用RNE ties-to-even，具体节点的符号、scale、乘数与移位以整数图为准。

CPU参考按letterbox预处理；板上网络输入来自中央裁剪后的双线性缩放。两种输入几何含义不同，比对前须统一预处理。

## 五路输出

| 输出 | NCHW形状 | 字节 |
|---|---|---:|
| P4框回归 | 1×4×20×20 | 1600 |
| P4分类logits | 1×10×20×20 | 4000 |
| P5框回归 | 1×4×10×10 | 400 |
| P5分类logits | 1×10×10×10 | 1000 |
| 道路logits | 1×3×80×80 | 19200 |

五路均为signed INT8，合计26200字节；前7000字节为检测数据。PS执行sigmoid、两级Top-K、框坐标恢复与道路logits插值/argmax，不执行NMS。

## 发布边界

仓库提供当前源代码和必要的模型、校准与UI输入资源。模型参数的二进制格式属于运行数据；`.bit`、`.hwh`、`.dcp`、原生动态库及训练检查点属于生成文件，不纳入源码仓库。

原工程的整机HDMI时序尚有已知限制，板端FPS和功耗尚未完成测量。应对自己构建的硬件执行完整数值、时序、接口与板端验证，不能由CPU参考或软件测试推断硬件结果。
