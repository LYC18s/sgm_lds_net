# 设计报告与大模型协作记录

本目录介绍 SGM 与 LDS-Net 道路感知系统的设计、优化、协作开发方法和复现步骤。建议先阅读设计报告，再结合源码查看协作案例及通用技能包。

| 文档 | 内容 |
|---|---|
| [设计报告](design_report.md) | 选题背景、创新点、原理与框图、软硬件划分、接口、优化对比、验证范围及复现步骤 |
| [大模型协作记录与技能包提炼](ai_collaboration.md) | 提示词与回答的重构案例、自我纠错过程、协作工作流、技能提炼方法、验证与失效边界 |
| [架构速览](architecture.md) | 主要模块、五路张量输出和发布范围的简要说明 |
