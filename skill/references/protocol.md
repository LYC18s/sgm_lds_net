# 协议、反压与波形采样

## 判定规则

| 规则编号 | 判定 | 归属 |
|---|---|---|
| VALID_DURING_RESET | 复位有效采样时 TVALID 未拉低 | 协议检查子集 |
| STALL_STABILITY | 前拍 valid=1/ready=0，当前拍撤销 valid 或改变有效数据/边带 | 协议检查子集 |
| STRB_WITHOUT_KEEP | 某字节 TSTRB=1/TKEEP=0 | 保留编码检查 |
| PACKET_LENGTH | 已确认完整的固定长度包在 TLAST 握手时长度不符 | 接口契约 |
| MISSING_PACKET_END | 声明完整窗口结束时仍有已传输的未结束包 | 接口契约/窗口声明 |
| VIDEO_EOL | 视频一行的 TLAST 位置与约定拍数不同 | 视频接口契约 |
| EARLY_SOF / MISSING_SOF | 未结束帧被新 SOF 打断，或边界已同步后帧外接收数据 | 视频接口契约 |
| INCOMPLETE_VIDEO_FRAME | 声明完整窗口结束时行/帧未结束 | 接口契约/窗口声明 |
| EXPECTED_COUNT | 完整窗口中包/帧总数不符 | 测试契约 |
| APPLICATION_NO_PROGRESS | 连续无握手超过配置期限 | 应用活性，不能单独判定协议违规 |
| CAPTURE_PENDING_BEAT | 声明完整窗口结束时还有待接收拍 | 事务完整性/窗口声明 |

TREADY 可以等待 TVALID；发送端不能把等待 TREADY 作为拉高 TVALID 的前提。受控实验可让接收端开始保持 TREADY=0，验证发送端有数据时仍能声明有效并保持，再释放反压。若源内部尚未有数据，波形无 TVALID 不能证明违规；静态依赖需要审查 RTL。

TVALID=0 时 payload 可变化，不做有效内容比较；保持性检查只比较上一个待接收拍中 TKEEP/TSTRB 表明的数据字节，空字节/位置字节的数据不误判。边带本身在阻塞期间仍需保持。TLAST 要在握手时计入包边界，持续多个阻塞周期的一个 TLAST 不是多个包。

只对确认复位有效的采样点检查复位行为；复位释放同步、复位脉宽、CDC 与所有规范条款不由当前离线工具完全证明。

## 采样方法

最小探针：ACLK、ARESETn、TVALID、TREADY、TDATA、存在的 TKEEP/TSTRB/TLAST/TUSER。若有路由/交织还需 TID/TDEST；若定位流水线，需要相邻接口同条件探针、FIFO 水位和溢出/丢帧计数。

ILA 记录：触发条件、前后窗口深度、采样时钟、是否存储限定、计数是否溢出、复位状态、端口层级和位宽。只记录握手的 ILA 样本无法证明阻塞稳定性，也无法直接估计利用率。

VCD 转换要求 ASCII 格式、精确层级映射、完整时钟。转换器按每次已知 0→1 边沿之前的值采样；与同步 RTL 在边沿消费旧值的方式对应。无已知时钟边沿或遇 `$dumpoff` 时拒绝。模拟竞争、未导出的时钟边沿、断续 dump 不能通过转换恢复。大 VCD 当前整体读入，过大文件先由仿真器导出有界完整窗口。

## 反压测试

- TREADY 先有效、TVALID 先有效、两者同拍出现。
- 单周期、连续长周期、固定种子随机反压；反压位置包括首拍、尾拍和包间。
- TVALID 气泡、连续包、单拍包、尾部部分字节、复位中断。
- 恢复后对照独立参考，检查丢失、重复、顺序及包边界，而非只数拍。
- 真实采集源无法停顿时，在桥接/FIFO 前建立不可暂停源模型；说明允许丢包/丢帧的策略、丢弃计数和重新同步边界。不能强迫传感器模型遵循下游 TREADY 来证明现实不会溢出。

`assets/tb_axis.sv` 提供确定性反压与故障注入，`make_examples.py` 提供固定种子的离线正常/异常证据。连接真实 DUT 后，需要把输出接受拍与独立参考关联；模板本身不证明用户算法。

## 包与视频边界

packet：长度按接收拍的保留字节累计；定长包按配置检查，变长包仅记录长度。未设置固定长度时，不声称检出了所有提前 TLAST。零字节尾拍是否允许还要按端点约束判断，不能把某 IP 的 TKEEP 限制当成所有 AXIS 的协议规则。

video：只在握手上读取 SOF/EOL，按每行拍数和每帧行数计数。中途开始的捕获等待首个被接受 SOF；下一 SOF 打断旧帧属于契约异常，允许丢帧的系统需另加恢复策略适配。

宽度转换前后的拍数不同，应比较有效字节序列与业务边界；不能直接要求两端握手拍数相等。跨时钟延迟需共同时基、关联标签或经过校准的计数器，不减去两个未同步周期计数。
